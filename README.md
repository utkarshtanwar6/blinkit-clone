# Blinkit Clone

A responsive front-end clone of the Blinkit quick-commerce platform, built using pure HTML5 and CSS3 to replicate its modern UI layout, product grids, and responsive design across desktop and mobile devices.

## Features
- **Responsive Navigation Bar:** Includes location selector, search bar, login button, and cart indicator.
- **Hero & Promotional Banners:** Styled promotional sections showcasing instant delivery categories and offers.
- **Category & Product Grids:** Clean, structured cards displaying product images, weights/quantities, pricing, and "Add" buttons.
- **Mobile-First Responsiveness:** Adapts smoothly across desktop, tablet, and mobile screen sizes using CSS Flexbox and Grid.
- **Footer Section:** Multi-column layout with useful links, categories, and app download badges.

## Tech Stack
- **HTML5** – Semantic markup and page structure
- **CSS3** – Custom styling, Flexbox, CSS Grid, and media queries
